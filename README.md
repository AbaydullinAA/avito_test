### Детекция ботов по истории событий
Для каждой куки оценивали, насколько её поведение похоже на бота. События преобразовали в одну строку числовых признаков; итоговая модель — градиентный бустинг.
- Метрика: Precision при Recall ≥ 70%. Нужно найти минимум 70% ботов, уменьшая число ложных срабатываний.
- Подготовка: оставили события внутри заданного окна, удалили полные дубли, объединили разные написания платформ. Повторные действия в разное время сохранили.
- Базовый вариант: Random Forest с количеством событий и уникальных товаров получил 0.1025 на 17–19 апреля.
- Время и разнообразие: добавили интервалы между действиями, длительность активности, разнообразие товаров, категорий и запросов. Средняя метрика Random Forest выросла с 0.3334 до 0.4616.
- Смена модели: бустинг на тех же признаках повысил средний результат до 0.5305.
- Курсор и платформа: расширили набор до 70 признаков; средняя метрика достигла 0.7127.
- Альтернативы: пробовали User-Agent, Extra Trees, усреднение прогнозов и другие настройки. Для отправки оставили одиночный бустинг.
- Валидация: обучали на ранних днях, проверяли на трёх следующих периодах. Итоговые значения: 0.6965, 0.6816, 0.7600. Средние выше рассчитаны по этим трём периодам.
- Скрытая проверка: 0.77831, константный ответ — 0.09391. Эти результаты относятся к отдельному тесту платформы.
Код находится в reshenie_clean.ipynb; зависимости и версия Python — в соответствующих файлах репозитория.
